# Установка и первый вход

[Оглавление](README.md) · [English](../en/installation.md)

## Подготовка

Нужны Linux, достаточно диска и ОЗУ, Docker/Compose и рабочий драйвер GPU.
Для NVIDIA требуется настроенный NVIDIA Container Toolkit; для AMD — доступ
к нужным устройствам GPU. Скачивание контейнера не исправляет драйвер хоста
и не применяет аппаратные анлоки.

Учитывайте размер образа, весов, временное место загрузки/распаковки и результаты.
Размер checkpoint не равен пику VRAM. CPU offload требует свободной ОЗУ и всё
равно использует VRAM для вычислений.

## Установщик

[install.sh](../../install.sh) загружает актуальный официальный установщик
по HTTPS. Поддержаны `auto`, `nvidia`, `amd`, `cpu`.

```bash
bash install.sh --help
bash install.sh nvidia --download-only
```

Вторая команда только сохраняет новый файл. Изучите его и выполните именно
напечатанное имя файла, если нужна установка проверенной версии.
`bash install.sh nvidia` повторно скачает и запустит актуальный вариант.

Перед выдачей прав администратора изучите действия скрипта: он создаёт панель
и обновлятор, может установить Docker. Не запускайте его поверх существующей
рабочей установки без резервной копии и плана переноса.

## Совместимость

| Оборудование | На что обратить внимание |
| --- | --- |
| Turing / CMP50HX | Совместимый образ и FP16-пресеты; модифицированные CMP50HX на 20 ГБ отличаются от штатных карт |
| Ampere / CMP170HX и новые поддерживаемые GPU | Подходящие NVIDIA runtime и рецепт модели |
| AMD, включая MI50/gfx906 | AMD-образ; разные семейства ROCm не взаимозаменяемы |
| CPU | Модель и движок должны поддерживать процессорный запуск |

Проверьте, что нужный тег и архитектура действительно опубликованы. Новым
функциям может требоваться более свежая сборка, даже с тем же номером версии.
Тег `-updater` нельзя использовать вместо образа основной панели.

## Первый вход

Адрес и порт смотрите в выводе установщика. Задайте уникальный первоначальный
пароль администратора и следуйте подсказкам первого входа. Изменение переменной
окружения не сбрасывает пароль уже существующего пользователя.

Активируйте свою лицензию, проверьте GPU и постоянное хранение, запустите
небольшую модель и один запрос. До настройки HTTPS и прав ограничьте доступ
локальной сетью. Compose, окружение, данные, модели и состояние обновлятора
храните вне контейнера и резервируйте; не загружайте эти файлы в GitHub.
